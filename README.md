# 本地端敏感資訊過濾機制 — 線上展示

> 這個 repo 只放一個靜態網頁，用途是把展示頁掛上 GitHub Pages。
> **原始碼與完整專案在 → https://github.com/JustinGNPS/tw-pii-filter**

## 線上展示

**https://weicheng28.github.io/tw-pii-filter-demo/**

貼一段文字進去，看它在送給雲端 AI 之前會變成什麼樣子，以及 AI 回覆後怎麼還原。

## 關於這個頁面

- **沒有後端。** 偵測、遮蔽、還原全部在你的瀏覽器裡執行，貼進去的文字不會離開你的電腦。
  本作品的核心主張就是「資料不出裝置」，展示頁自己也必須做到。
- **跑的是真的偵測。** 頁面裡的偵測邏輯直接取自瀏覽器擴充的 TypeScript 實作
  （`extension/src/`），不是為了展示另外寫的簡化版或預錄資料。
- **只跑規則層（L1）。** 語意層需要下載 NER 模型權重，不適合放進網頁；頁面上已標明這件事。
- **範例資料全部是公開的教科書測試值**（`A123456789`、`12345675`、Visa 測試卡號等），
  不含任何真實個資。

## 這個頁面怎麼產生的

由主 repo 的 `site/` 目錄建置而成（`npm run build` 產出單一 HTML 檔）。
要修改內容請改主 repo 的 `site/`，不要直接改這裡的 `index.html`。
